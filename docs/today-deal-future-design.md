# 楽天お買い得日の将来自動更新設計

## 現在の運用（第1段階）

- 日本時間の日付で、1日・5と0のつく日・18日は当日の短い案内を表示する。
- 通常日は、次のお買い得日を自動計算して日付つきで案内する。
- LPに設定したマラソン期間中は、急ぎ・限定クーポンなら購入もありと伝えたうえで、次のお買い得日も案内する。
- 倍率、上限ポイント、エントリーURLは固定で書かない。
- 開催条件は変わる可能性があるため、「条件や詳細は楽天市場でチェックしてね！」を必ず添える。

## 将来の運用（第2段階）

毎日0:00（日本時間）に、楽天市場の公開中の公式キャンペーンページだけを確認する。

1. 公式ページから、キャンペーン名・開催日・倍率・上限ポイント・エントリーURLを取得する。
2. URLのドメインが楽天公式であることと、開催日が当日であることを確認する。
3. 必須項目が揃った時だけ `marathon/today-deal-conditions.json` を更新する。
4. ページ側は、`verified_at` が当日（日本時間）で、必要項目が揃ったJSONだけを詳しい案内として表示する。

## 安全策

- ページが公開されていない、取得に失敗した、表記を判断できない場合は推測しない。
- その場合は第1段階の短い案内を表示し、確認が必要なことだけを記録する。
- AIの判断が必要な曖昧な条件は、人が確認してから公開する。
- 秘密情報は使わず、公開ページのみを確認する。
